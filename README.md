Bu proje, Qt Framework kullanılarak geliştirilen bir loglama programıdır. Task'ta yazdığı üzere günlük, saatlik, dakikalık, saniyelik olacak şekilde log kaydı tutmaktadır.
Log kayıtları, /build klasörünün içinde "/logs" klasöründe, her bir log ayrı olacak şekilde tutulmaktadır. Program yedi kere çalıştığında, yedi adet log kaydı görülmektedir.
Sekinci kez çalıştırdığınızda, ilk yazdığı logu silmektedir. Tüm bu işlemler console kısmında görülebilir.
